# Design directions

Three options, previewed on the real homepage. None is applied.
To apply one, paste its `:root` block over the one at the top of `assets/style.css` (plus any extra rules in the file).

- `a-sage-editorial.css`: the current look. Warm paper, sage green, soft cards.
- `b-ink-and-gold.css`: premium consultancy. Deep ink, brass-gold accent, tighter radius.
- `c-clean-signal.css`: modern SaaS clarity. White, cobalt-blue accent, crisp 10px corners.
- `d-gulf-sand.css`: regional warmth. Sand paper, terracotta accent, deep teal panels.
